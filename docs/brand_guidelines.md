# Kongila + Remotan — Complete Brand Guidelines

## 01 — Introduction & Brand Overview
These brand guidelines define the visual identity, voice, and design standards for Kongila and its operational platform, Remotan. They exist to ensure that every touchpoint — digital, print, or verbal — communicates a consistent, professional, and compelling brand experience.

### Our Mission
To build the most competitive remote work infrastructure in Africa, connecting exceptional talent across key emerging markets with clients in developed economies, enabling efficient and reliable operational delivery.

### The Brand Story
Africa's workforce is one of the world's most underutilised competitive assets. Kongila was built on the conviction that geography should never determine opportunity. We are building the infrastructure layer that empowers African professionals to work with the world's best organisations — and we are doing it with the rigour, technology, and accountability that global clients demand.

### Brand Promise
> **"We deliver deployment-ready talent and operational excellence — so you can build globally, from Africa."**

### Brand Values
*   **Excellence** — We hold ourselves to the highest standards of quality and delivery.
*   **Integrity** — We operate with transparency and honesty at every level.
*   **Reliability** — Clients and talent can depend on us to deliver, consistently.
*   **Innovation** — We leverage technology and intelligence to stay ahead.
*   **Empowerment** — We create pathways for African talent to reach their full potential.
*   **Accountability** — Every outcome is owned, measured, and improved.

### Brand Personality
Kongila is confident without arrogance. Professional but not cold. Progressive but grounded. Think: a world-class institution with the energy of a challenger brand.

| Trait | Expression |
| :--- | :--- |
| **Confident** | Bold headlines, direct copy, strong primary blue |
| **Intelligent** | Structured layouts, data-forward design, precise typography |
| **Human** | Warmth in photography, approachable voice, inclusive imagery |
| **Global** | Clean, international aesthetics; multilingual-ready design |
| **Trustworthy** | Consistent identity, transparent communication, professional finish |

## 02 — Brand Architecture
Kongila operates a master brand / sub-brand architecture. Kongila is the parent brand and infrastructure entity, while Remotan is a distinct product brand that sits within the Kongila ecosystem.

### Brand Hierarchy

| Level | Brand | Description |
| :--- | :--- | :--- |
| **Master Brand** | **Kongila** | Employer of Record, talent platform, client-facing |
| **Product Brand** | **Remotan** | Multi-client SaaS operational platform, subscription-based |

### Brand Relationship
Kongila is the infrastructure company. Remotan is the operating system that powers service delivery. Kongila is just one of Remotan's clients, meaning Remotan can serve other organisations beyond the Kongila ecosystem.

Visually, Remotan carries its own identity while maintaining clear heritage from Kongila through shared typographic and structural principles. The two brands should never appear visually identical.

> [!WARNING]
> **Rule**: Kongila brand assets are not interchangeable with Remotan brand assets. Always identify the correct brand context before applying any identity element.

## 03 — Logo System

### Primary Logo
The Kongila primary logo consists of two elements: the logomark (symbol) and the wordmark (logotype). Together they form the full lockup. The symbol is a bold, geometric 'K' composed of angular shapes arranged within a rounded square — representing precision, structure, and forward movement.

### Logo Construction
*   **Logomark**: Uses a dark blue (`#0047CC`) rounded square container with a white geometric K composed of four angular planes.
*   **Wordmark**: Set in a bold, modern sans-serif directly to the right of the symbol, using the same primary blue.

### Logo Variants

| Variant | Usage |
| :--- | :--- |
| **Full Lockup (Horizontal)** | Primary usage — digital, print, presentations, email signatures |
| **Symbol Only** | Favicon, app icon, social media avatar, embossed print, very small sizes |
| **Wordmark Only** | Co-branding contexts where symbol would clutter; horizontal banners |
| **Reversed (White)** | Use on dark or photographic backgrounds — never on mid-tone backgrounds |
| **Single Colour (Dark Navy)** | Single-colour print (letterpress, emboss, stamps) |
| **Single Colour (White)** | Screenprint on merchandise, dark swag items |

### Logo Clear Space
The minimum clear space around the logo is defined by the height of the 'K' symbol (designated as `1x`). No other graphic element, text, edge, or fold should encroach on this protected zone.

$$\text{Minimum Clear Space Rule: All sides } = 1x \quad (x = \text{height of logomark symbol})$$

### Minimum Size

| Use | Minimum Size |
| :--- | :--- |
| **Digital (Full Lockup)** | 120px wide |
| **Print (Full Lockup)** | 30mm wide |
| **Symbol Only (Digital)** | 24px |
| **Symbol Only (Print)** | 8mm |

### Logo Dos and Don'ts

| ✓ DO | ✗ DON'T |
| :--- | :--- |
| Use the approved logo files only | Do not stretch or distort the logo |
| Maintain clear space on all sides | Do not recolour the logo outside approved palette |
| Use the reversed (white) version on dark backgrounds | Do not add drop shadows, outlines, or effects |
| Scale the logo proportionally | Do not place the logo on a busy or clashing background |
| Use the correct format for the medium (SVG for digital) | Do not recreate the logo in any typeface or software |
| | Do not rotate or flip the logo |
| | Do not use the logo smaller than minimum size |

### File Formats & When to Use

| Format | Use Case |
| :--- | :--- |
| **SVG** | All digital applications — websites, apps, UI (preferred) |
| **PNG (transparent)** | Digital presentations, email, social media, documents |
| **EPS / AI** | Print production, large format, vendor supply |
| **PDF** | General print documents, proposals |
| **JPG** | Use only when transparency is not supported (avoid where possible) |

## 05 — Typography
Typography is the backbone of Kongila's communication. Our type system is clean, modern, and highly functional — designed for digital-first delivery with strong print compatibility.

### Primary Typeface — Inter
Inter is Kongila's primary typeface for all digital applications. It is designed specifically for screen readability.

*   **Inter Black (900)**: Display headlines, hero text, major section titles.
*   **Inter Bold (700)**: Sub-headings, card titles, labels, CTAs, callouts.
*   **Inter SemiBold (600)**: Navigation items, table headers, captions needing emphasis.
*   **Inter Medium (500)**: Body copy in compact UI contexts, secondary labels.
*   **Inter Regular (400)**: Body copy, descriptions, long-form content.
*   **Inter Light (300)**: Pull quotes, decorative display text (use sparingly).

### Secondary Typeface — Sora
Sora is used for key marketing headlines, campaign copy, and display contexts where Inter needs a warmer, more characterful counterpart.

*   **Sora Bold (700)**: Campaign headlines, hero taglines, large-format print.
*   **Sora SemiBold (600)**: Sub-display text in marketing materials.
*   **Sora Regular (400)**: Pull quotes in editorial layouts.

### Print Fallback — Arial / Arial Bold
When Inter or Sora are unavailable, Arial and Arial Bold serve as the approved fallback.

### Type Scale — Digital

| Level | Font & Weight | Size | Line Height | Letter Spacing |
| :--- | :--- | :--- | :--- | :--- |
| **Display** | Sora Bold | 56–72px | 1.1 | -0.02em |
| **H1** | Inter Black | 40–48px | 1.15 | -0.01em |
| **H2** | Inter Bold | 28–32px | 1.2 | -0.005em |
| **H3** | Inter SemiBold | 20–24px | 1.3 | — |
| **H4** | Inter SemiBold | 16–18px | 1.4 | — |
| **Body Large** | Inter Regular | 18px | 1.7 | — |
| **Body Default**| Inter Regular | 16px | 1.7 | — |
| **Body Small** | Inter Regular | 14px | 1.6 | — |
| **Caption** | Inter Medium | 12px | 1.5 | — |
| **Label / Tag** | Inter SemiBold | 11–12px | 1.4 | 0.05em (UPPERCASE) |
| **Code** | JetBrains Mono | 14px | — | Technical documentation only |

### Typography Dos and Don'ts

| ✓ DO | ✗ DON'T |
| :--- | :--- |
| Use Inter as the default for all digital copy | Do not use more than 2 typefaces in a single layout |
| Maintain the type hierarchy consistently | Do not use decorative or script fonts |
| Use uppercase labels sparingly | Do not set body copy in uppercase |
| Use adequate line spacing (min 1.5 for body) | Do not use font sizes below 10pt/12px |
| Align text consistently (left-align body copy) | Do not justify body text (avoid river patterns) |
| | Do not mix Inter and Sora within a single sentence |

## 06 — Iconography & Illustration

### Icon Style
Kongila uses a line-icon system as the default. Icons are geometric, minimal, and drawn on a $24 \times 24\text{px}$ grid.
*   **Stroke weight**: 1.5px
*   **Corner radius**: 2px on rectangular forms
*   **Color**: Follows text/context color (never decorative color for its own sake)

### Recommended Icon Libraries
*   **Phosphor Icons** — Primary library (available in React, SVG, and webfont).
*   **Lucide Icons** — Acceptable secondary library for Remotan product UI.
*   **Custom Icons** — Commission custom icons matching the Phosphor stroke style.

## 07 — Photography & Imagery

### Photography Philosophy
Photography should tell the story of real people doing real, meaningful work. The Kongila visual world is human, aspirational, and global — it shows African talent thriving in professional environments, collaborating across borders, and delivering excellence.

### Photography Direction
*   **People**: Diverse, professional, natural lighting. Candid moments preferred.
*   **Environment**: Clean home offices, professional co-working spaces, modern workplaces. Light-filled.
*   **Technology**: Laptops, monitors, clean desk setups. No third-party logos visible.
*   **Culture**: African cities, communities, and contexts shown with pride and modernity.
*   **Collaboration**: Video calls, dual screens, suggesting connection across geographies.

### Photo Treatment
*   **Tonal Overlay**: Apply a subtle cool blue tone overlay (10–15% opacity Kongila Blue) for marketing contexts to unify stock images.
*   **Duotone**: A Kongila Blue / Near Black duotone is approved for hero images.
*   No heavy filters, HDR, or artificial saturation boosts.

## 10 — UI & Digital Design Language

### Design Principles
1.  **Clarity first** — Every screen should communicate one primary action.
2.  **Density is earned** — Show detail only when the user is ready for it.
3.  **Consistency builds trust** — Use components, not custom solutions.
4.  **Accessible by default** — WCAG 2.1 AA minimum; AAA preferred.
5.  **Performance is design** — Optimise for fast-loading, mobile-first experiences.

### Grid & Layout
*   **Desktop Grid**: 12-column, 1280px max-width, 24px gutters, 80px outer margins.
*   **Base Spacing Unit**: 8px (all spacing in multiples of 8: 8, 16, 24, 32, 48, 64, 96, 128).
*   **Border Radius**: 4px (small), 8px (default), 12px (cards), 24px (pills/badges), 50% (avatars).

### Component Tokens
*   **Primary Button**: Kongila Blue fill, white text, Inter SemiBold 14px, 8px radius, 40px height.
*   **Secondary Button**: White fill, Kongila Blue border (1.5px), Kongila Blue text.
*   **Form Inputs**: White fill, Mid Grey border (1px), 8px radius, 40px height, 12px padding. Focus state has a Kongila Blue border (2px) and blue glow (`0 0 0 3px rgba(0,71,204,0.15)`).
*   **Cards**: White background, 1px Mid Grey border (or shadow), 12px border radius, 24px padding.

## 11 — Motion & Animation Principles
*   **Micro interactions**: 100–150ms, ease-out.
*   **Component transitions**: 200–250ms, ease-in-out.
*   **Page transitions**: 300–400ms, ease-in-out.
*   **Easing default**: `cubic-bezier(0.4, 0, 0.2, 1)` — Material-style smooth.
*   **Loading states**: Use skeleton screens (not spinners) for content-loading states.

## 17 — Brand Application Examples

### Correct Applications
*   **Website Hero**: Kongila Blue gradient background, white Sora Bold headline, white primary CTA button, and talent photography with blue tonal overlay.
*   **Swag / Merchandise**: Kongila symbol on white t-shirt in Kongila Blue, or white symbol on Kongila Blue t-shirt.
*   **Proposal Document**: Kongila Blue cover page, Near Black headings, blue rule dividers, proposal table with blue header row.

### Common Brand Mistakes to Avoid
*   Placing the logo on a background that provides insufficient contrast.
*   Using a non-brand blue (e.g., Canva's default blue) that looks "close enough".
*   Mixing typefaces from outside the approved type system (Inter and Sora).
*   Using the Remotan teal colour in Kongila contexts or vice versa.
